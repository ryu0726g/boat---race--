# BOAT AI Lab

個人利用向けの競艇予想MVP。GitHub Pagesだけでまず動く静的版です。

## 現在できること
- 6艇の基礎データ入力
- 展示前 / 展示後の評価更新
- 数値ロジックによる艇評価・3連単確率順位
- 「丸亀5R程度の自信度」を意識した買い / 見判定
- 本線のガミを避けるための100円単位の自動資金配分
- レース結果・払戻・的中率・回収率・収支をlocalStorageに保存

## 予想ロジック（v0.1）
基礎データを主、展示を補正として使います。
1. 級別
2. 全国勝率 / 当地勝率
3. 想定コース別1着率
4. モーター2連率
5. 今節指数
6. 展示タイム順位
7. 展示ST順位（比重は小さめ）

展示最遅だけで消す、展示STだけで頭固定する、といった極端な判断はしません。

## 資金配分
- 3連単のみ
- 100円単位
- 上位本線2点について「総投資 × 本線最低払戻倍率」を超える購入額を先に確保
- それで予算を超える場合は見送り
- 残額を `推定確率 × オッズ` の高い候補へ100円ずつ配分

## GitHub Pages
Settings → Pages → Deploy from a branch → main / root を選択すれば公開できます。
